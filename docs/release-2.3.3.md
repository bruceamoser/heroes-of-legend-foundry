# Heroes of Legend 2.3.3

- Add level correctly unlocks earned class signatures. Existing characters with
  missing pending markers can choose their unchosen signatures immediately.
- Players can change signatures at earned tiers from the character sheet.
  Switching replaces the class-granted choice and preserves separately purchased
  signatures, DP, existing equipment and unfinished development drafts.
- Repeated switches retain acquisition receipts to avoid repeated equipment grants.
