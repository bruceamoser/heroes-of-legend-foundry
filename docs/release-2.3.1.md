# Heroes of Legend 2.3.1

- Player-character tokens link to their Actor. Existing unlinked character changes
  copy back before linking; original Actor data and token deltas are preserved for
  recovery. Creature and summon copies remain independent.
- Supplies align in compact rows. Inventory uses a pencil beside each name.
  Equipment editing focuses on the item's name, inventory values and description.
- Weapon attack cards show the selected weapon's name.
- Completed wound recovery removes its mechanical penalties while retaining the scar.
- Encounters group players and creatures and offer End combat at the bottom.
- Your own level changes refresh development without a false ledger warning.
