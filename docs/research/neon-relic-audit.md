## Reuse boundary

Start a clean implementation. Reuse ideas: typed records, V2 sheet parts, localized labels, source/generated separation, deterministic content identity and first-run guidance. Any actual copied source requires checking the file's license and preserving required notices. Do not copy the repository wholesale, its historical migrations, game-specific dice implementation, mission content or its CI configuration unchanged.

No exhaustive vestigial-code finding is claimed. In particular, this audit did not establish a running V1 sheet dependency or demonstrate a broken ActiveEffect payload in Neon Relic. The actionable result is a verified list of reference patterns and concrete risks for HOL, not a generalized claim that a V13-origin system is obsolete.
